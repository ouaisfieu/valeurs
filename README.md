# 🧭 Boussole de Valeurs

> Un outil interactif pour explorer, identifier et visualiser vos valeurs personnelles.

## 🌟 Accès direct

**🎯 [Utiliser la Boussole de Valeurs](https://ouaisfieu.github.io/boussole/)**

+ Retrouvez la boussole sur [Obsidian](https://publish.obsidian.md/ouaisfieu/%E2%96%B6+NOS+KITS+%E2%97%80/%E2%98%AF+VALEURS/%F0%9F%9F%A2+Valeurs)

## 📖 À propos

Cette boussole de valeurs vous aide à :
- Explorer 8 catégories de valeurs humaines
- Sélectionner jusqu'à 10 valeurs prioritaires
- Visualiser votre profil de valeurs
- Exporter vos sélections pour Obsidian

## 🗂️ Structure

### Catégories de valeurs

1. **Morales et Éthiques** - Justice, Honnêteté, Intégrité...
2. **Sociales** - Altruisme, Solidarité, Coopération...
3. **Personnelles** - Liberté, Authenticité, Créativité...
4. **Réalisation** - Succès, Excellence, Ambition...
5. **Spirituelles** - Sagesse, Épanouissement, Transcendance...
6. **Environnementales** - Durabilité, Respect de la nature...
7. **Esthétiques** - Beauté, Harmonie...
8. **Politiques** - Démocratie, Droits de l'homme...

## 💡 Comment utiliser

1. Visitez [la boussole](https://ouaisfieu.github.io/boussole/)
2. Explorez les différentes catégories de valeurs
3. Sélectionnez jusqu'à 10 valeurs qui résonnent avec vous
4. Visualisez votre profil dans la boussole radar
5. Exportez vos valeurs au format Markdown pour Obsidian
